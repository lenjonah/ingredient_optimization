# Ingredient optimization

Project to optimize a cell growth media formulation, consisting of 30 different ingredients to maximize the cell growth rate as well as the cell morphology while minimizing the total ingredient cost. Data from an initial random screening is explored and based on these data the most relevant ingredients are determined that impact the cell growth rate and morphology. Using Bayesian optimization the next set of experiments are determined that balance exploration and exploitation. For more details view the notebook `ingredient_optimization.ipynb`.
